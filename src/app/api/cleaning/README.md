# `src/app/api/cleaning/`

> Cleaning endpoints (grouped).

| Layer | Owner |
|---|---|
| API route | Akash |

## What this folder is for

This folder only groups its four sub-folders; it has no `route.ts` of its own.

## Sub-folders

- `slots/` : Availability of slots.
- `bookings/` : Create a booking.
- `schedule/` : List booked rooms.
- `export/` : Download the schedule.
